Connect your model

Run PromptCanary locally. Copy .env.example to .env, fill in your provider settings, then restart the server. 

LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=your-model-id
LLM_API_KEY=your-api-key

Local compatible servers can use an HTTP localhost endpoint without an API key. Model calls leave your machine for the configured provider.

The hosted demo supports fixture playback only. Live calls require the local Node.js server.
